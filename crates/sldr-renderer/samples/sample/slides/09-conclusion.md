# Where this leaves us

Three things to take away.

- **Don't fight the curve.** If a method gets better with scale, build for that path.
- **Keep the substrate small.** The thing you write by hand should be the thing that stays stable.
- **Make the corpus do the work.** Examples beat rules; data beats taste; scale beats cleverness.

None of this is a verdict on craft. It's a note on which curves keep going up.
