# What is sldr?

sldr compiles markdown slides into self-contained presentations. Content lives in slide files, structure in layouts, style in flavors — so you write a slide once and reuse it in any deck, with any brand, forever.

No node. No runtime. One binary, plain text in, a presentation out.
