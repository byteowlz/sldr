# Three guarantees

- **Deterministic** Same inputs produce byte-identical output. Diff your decks like code.
- **Restylable** `--flavor` swaps the entire look without touching one word of content.
- **Curatable** Slides outlive decks: build tomorrow's talk from yesterday's library.
