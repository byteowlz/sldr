# Flavors are the style layer

Colors, fonts, spacing, shadows, motion — all named tokens in one TOML file.

Rebuild this deck with `--flavor aurora` or `--flavor letterpress` and not a word changes. That diagonal panel? It is painted with this flavor's accent token.
