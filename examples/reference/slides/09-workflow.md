# From zero to deck

- **init** One command creates the library: slides, playlists, flavors, layouts.
- **write** Slides are markdown files; fuzzy names mean no paths to remember.
- **playlist** Pick slides from the library, in order. That is the whole deck definition.
- **build** Deterministic HTML, offline-ready. Rebuild any time, byte-identical.
