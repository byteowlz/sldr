# Splitting content

::left::
**This column** comes from a `::left::` marker in the markdown — plain text, no HTML.

```markdown
::left::
First column...
::right::
Second column...
```

::right::
**This column** follows `::right::`. The same markers feed any column layout — switch `layout:` between `two-cols` and `versus` without touching the text.
